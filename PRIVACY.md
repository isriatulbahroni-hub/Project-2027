# Kebijakan Privasi Planner OS (draft)

> Draft. Sesuaikan sebelum dipakai untuk produk yang dijual, dan konsultasikan ke ahli hukum kalau perlu.

- Semua data yang kamu isi (tugas, jadwal, jurnal, keuangan, mood, dan lainnya) disimpan hanya di perangkatmu lewat penyimpanan browser. Data tidak dikirim ke server kami.
- Belum ada akun, login, atau pelacakan pengguna di versi web ini.
- Menghapus data browser, memakai mode privat, atau berganti perangkat akan menghilangkan data. Pakai **Ekspor data (JSON)** di menu Downloads untuk cadangan.
- Situs ini di-host di Vercel, yang dapat mencatat log akses standar (alamat IP, waktu, halaman) sesuai kebijakan Vercel.
- Halaman kesehatan hanya untuk pencatatan pribadi dan bukan nasihat medis.
